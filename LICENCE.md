## 🧩 About

**Avowed Hack Menu** is a curated list of Avowed open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap, compass
- **Quality-of-Life Helpers** — inventory catalog, quest log, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Combat Overlay — visualize enemy positions and health bars
- Damage Numbers — show floating damage values for study
- Stamina Meter — extended stamina visualization
- Dodge Cooldown — track dodge timing

### Wallhack
- Item Catalog — browse weapons, armor, and consumables
- Custom Loadout Notes — organize equipment sets
- Loot Highlighter — highlight nearby containers and resources

### Aimbot
- Minimap Overlay — enlarged map with markers
- Waypoint Notes — save and review custom waypoints
- Compass Helper — improved directional indicator
